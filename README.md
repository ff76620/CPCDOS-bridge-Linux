CPCDOS bridge Linux est une couche d'exécution permettant à CPCDOS de fonctionner sous Linux avec intégration système native.

Fonctionnalités :

Bridge Python CPCDOS ↔ Linux
Exécution de commandes système
Launchers Linux
Intégration X11
Notifications Linux
VLC / audio / scripts shell
Support Ubuntu/Debian
Helper système compilé en C
